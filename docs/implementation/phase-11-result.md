## Option A settings sequence

A staged Hot Application that needs generation-validated settings reserves one final numeric authorization generation in `pending-configuration`. It is a foreign-key fence only and never authorizes. Required fields may remain visibly unset while the runtime operation waits. A leased coordinator validates the exact verified runtime generation, promotes settings atomically, and returns one immutable receipt. Activation rejects an unterminalized target, then promotes that exact reserved generation to `current`. Reinstall values move only through explicit current-authority, server-derived adoption onto the new descriptor; the browser cannot select either generation or retained values.
